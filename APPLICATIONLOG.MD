1. What is Application Logging?
Application logging is the process of recording important events, activities, warnings and errors generated by an application.

It helps developers:
- Monitor application behavior.
- Identify errors.
- Debug problems.
- Track API requests.
- Maintain application reliability.
2. Console Logging vs File Logging
So far, our logs appear in the terminal.

There are two common ways to store logs:

Console Logging
- Displays logs in the terminal.
- Useful during development.
- Logs disappear when the terminal output is cleared.
File Logging
- Saves logs into a .log file.
- Helps investigate previous errors.
- Useful for monitoring applications over time.
3. Logging to a File
Python's logging module supports file logging through FileHandler or basicConfig().

Example:
import logginglogging.basicConfig(    filename="app.log",    level=logging.INFO,    format="%(asctime)s - %(levelname)s - %(message)s")logger = logging.getLogger("tool_library")logger.info("Application started")logger.warning("Tool not found")logger.error("Database error")


This creates an app.log file and stores the messages.
4. Why File Logging?
Imagine our Tool Library API runs continuously.

If an error occurs at 2 PM but we check the application at 5 PM, terminal output might no longer be available.

File logging allows us to inspect the earlier events.
5. Important Concepts
Concept	Purpose
Logger	Generates log messages
Handler	Determines where logs are sent
Formatter	Controls log message format
FileHandler	Saves logs to a file
StreamHandler	Sends logs to the console
Logging level	Controls which messages are recorded


6. Interview Questions
Q1. What is FileHandler?

FileHandler is used to write logging messages into a file.

Q2. What is a logging formatter?

A formatter defines how log messages appear, including timestamp, severity level and message.

Q3. Why do we use file logging?

To maintain historical records of application events and errors for debugging and monitoring.
